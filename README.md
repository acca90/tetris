# Pixel Boy Tetris

Pixel-art Tetris inside a Game Boy–style handheld, with Korobeiniki synthesised live in the
browser. Plain HTML/JS — no build step, no dependencies.

## Run with Docker

```bash
git clone https://github.com/acca90/tetris.git
cd tetris
docker compose up -d
```

Open <http://localhost:8080> and press **Enter** to power on.

Use another port with `TETRIS_PORT=9000 docker compose up -d`. Stop with `docker compose down`.

Without Compose:

```bash
docker build -t pixel-boy-tetris .
docker run -d --name pixel-boy-tetris -p 8080:8080 --restart unless-stopped pixel-boy-tetris
```

The image is nginx (unprivileged, Alpine) serving `index.html` and `assets/` on port 8080.

## Run without Docker

Open `index.html` directly in a browser.

## TrimUI Brick (and other RetroArch handhelds)

`brick/` is a C port of the game as a **libretro core**, so it runs inside RetroArch on the device —
no system libraries needed beyond libc (built against GLIBC 2.17). It draws the Pixel Boy screen
at 256×192 with a slim bezel and upscales 4× to the Brick's 1024×768 panel itself.

```bash
brick/build-brick.sh        # cross-compiles in Docker -> brick/dist/PixelTetris/
```

Copy `brick/dist/PixelTetris/` to `/mnt/SDCARD/Apps/` on the stock TrimUI OS card; it appears in
**Apps** as *Pixel Tetris*. Best score is kept in RetroArch's saves dir as `pixeltetris.hi`.
Exit via the MENU button → Quit RetroArch.

| Button | Action |
|---|---|
| D-pad ← → | Move |
| ↓ | Soft drop |
| ↑ | Hard drop |
| A / B | Rotate clockwise / counter-clockwise |
| X / Y / L / R | Hold |
| Start | Start / pause |
| Select | Mute |

For desktop testing: `make -C brick && retroarch -L brick/build/native/pixeltetris_libretro.so`,
or run the scripted headless check `python3 brick/tools/harness.py brick/build/native/pixeltetris_libretro.so /tmp/out`.

## Controls

| Key | Action |
|---|---|
| ← → | Move |
| ↑ / Z | Rotate clockwise / counter-clockwise |
| ↓ | Soft drop |
| Space | Hard drop (A button) |
| E | Hold (B button) |
| Enter / P | Start / pause |
| M | Mute (Select) |

The buttons on the device are clickable too.

## Art

Every sprite is generated by `art/make-sprites.lua` in [Aseprite](https://www.aseprite.org/),
which also writes `assets/layout.js` (screen and button coordinates the game reads).
Regenerate after editing the script:

```bash
aseprite -b --script-param root=$PWD --script art/make-sprites.lua
```

The `.aseprite` files in `art/` are the editable outputs.

The UI caption font (Press Start 2P) loads from Google Fonts; the game itself uses its own
pixel font and works offline.
